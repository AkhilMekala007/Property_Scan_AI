# LLD 12 — C13 Output contract and `scan run`

**Goal:** the brief's output contract — one command per capture, JSON to a published schema, a rendered plan, and a confidence interval on every measurement.

```
scan run <capture>
   ──► run_pipeline (QC → drift → labels → structure → rooms → measure → openings → stitch → damage → rules)
   ──► build_result ──► Result (Pydantic, validated) ──► result.json
   ──► plan.png (stitched plan + damage)    qc_report.md / .json
```

## Modules

| File | Responsibility |
|---|---|
| `scan/contract/schema.py` | The contract as Pydantic models (`extra="forbid"` everywhere); `json_schema()` |
| `scan/contract/budget.py` | Provisional per-tier error budget; `Z90` |
| `scan/contract/build.py` | `measure()` (value + σ → 90 % interval) and `build_result()` |
| `schema/result.schema.json` | Published schema, generated by `scan schema`; a test fails if it drifts from the models |
| `scan/stitch/render.py` | `render_floor_plan(..., damage=)` draws floor/ceiling damage outlines and wall damage markers |

## Contract decisions

- **Every number is a `Measure`:** `value`, `lo`, `hi`, `sigma`, `unit`, `confidence` (0.9), `bound` (`two_sided` or `lower`), `calibrated`. A door head that was never seen is a lower bound (`hi: null`).
- **Stable surface ids:** `room_N.wall_K`, `room_N.floor`, `room_N.ceiling`. Damage, flags and scope items all refer to these, so a line item can be traced to the surface and the damage that caused it.
- **Missing is explicit:** e.g. `ceiling_height: null` with `ceiling_note: "ceiling not observed during capture (QC)"`; walls carry `observed` and `coverage`.
- **Strict:** unknown fields and invalid enums (e.g. a damage class outside `water_stain | crack | mold`) fail validation.
- **Provenance:** `processing` records pipeline version, UTC time, runtime, offline flag, drift-correction summary, interval method, and every model used with its repository and licence.

## Interval method (until C12)

σ_total = √(σ_fit² + σ_sys²), interval = value ± 1.645 σ_total, clipped at 0 for non-negative quantities. Systematic terms per tier (`budget.py`):

| Quantity | LiDAR | Video | Photo |
|---|---|---|---|
| Wall length | 1 cm + 0.3 % | 3 cm + 1.5 % | 6 cm + 4 % |
| Wall face position (→ area: perimeter × this) | 0.7 cm | 3 cm | 6 cm |
| Ceiling height | 1 cm | 4 cm | 8 cm |
| Opening width / height | 1.5 / 2 cm | 4 / 5 cm | 8 / 10 cm |
| Damage area / length | 15 % / 5 cm | 25 % / 10 cm | 35 % / 15 cm |

These are placeholders marked `calibrated: false`. C12 fits them on the tape-measured benchmark so that ~90 % of true values fall inside the reported intervals.

## Exit codes

`0` success; `1` written but the capture has QC errors or rooms overlap; `2` the capture could not be read.

## Result on `single_scan_with_ceiling` (`--device "iPhone 15 Pro"`)

5 rooms, net 59.91 m² [59.15, 60.68], connected; ceilings 2.29–3.07 m with ±1.7 cm intervals; 7 openings; 0 damage (clean capture); runtime 110 s with cached labels and detections. One room overlap is reported (exit 1) — the room-level instability recorded as the fix-loop candidate (`docs/fix_loop.md`).

## Tests (`tests/test_contract.py`)

Interval arithmetic, lower bounds, non-negative clipping; `build_result` on a synthetic two-room plan with a shared wall, a door seen from both rooms and a ceiling stain (shared wall 0.10 m, opening wall ids, surface ids, R01 flag and scope on `room_1.ceiling`, `calibrated: false`); JSON round trip with the `class` key; invalid class and unknown fields rejected; the published schema equals the generated one.
